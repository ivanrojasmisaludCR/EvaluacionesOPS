# Proposal

## Why

El usuario necesita conocer las direcciones de las funcionalidades y acceder mediante un menú.

## What Changes

- Menú desplegable en el encabezado con Inicio, Talleres, Instrumentos, Importar Excel y Participar.
- Enlace directo /instrumentos#importar que se recupera al recargar.
- Documentación de rutas generales y las que dependen de una sala o versión.

## Capabilities

### New Capabilities

- `navegacion`: Acceso común a las funciones implementadas.

## Impact

Solo interfaz y documentación. Sin nuevas dependencias, migraciones ni cambios de permisos HTTP.
